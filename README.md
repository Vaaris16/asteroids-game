# ASTEROIDS

**Asteroids** is a recreation of the classic [*Asteroids*](https://en.wikipedia.org/wiki/Asteroids_(video_game)) arcade game, built entirely in **Rust** using the [**Bevy game engine**](https://github.com/bevyengine/bevy).
